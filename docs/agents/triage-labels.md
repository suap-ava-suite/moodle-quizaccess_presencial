# Etiquetas de triagem

Este mapeamento relaciona os papéis usados pelas habilidades às etiquetas do GitHub.

| Papel da habilidade | Etiqueta no GitHub | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Aguarda avaliação do mantenedor. |
| `needs-info` | `needs-info` | Aguarda informações de quem relatou a solicitação. |
| `ready-for-agent` | `ready-for-agent` | Tem especificação suficiente para implementação por agente. |
| `ready-for-human` | `ready-for-human` | Requer implementação humana. |
| `wontfix` | `wontfix` | Não será implementada. |

Quando uma habilidade mencionar um papel de triagem, use a etiqueta correspondente desta tabela.

Reutilize as etiquetas existentes. Quando uma operação autorizada de triagem precisar de uma etiqueta ausente, crie-a com o nome desta tabela.
