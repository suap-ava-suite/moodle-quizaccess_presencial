# Rastreador de issues

As issues deste projeto ficam no [GitHub de suap-ava-suite/moodle-quizaccess_presencial](https://github.com/suap-ava-suite/moodle-quizaccess_presencial/issues).

Leia a issue e seus comentários pelo conector GitHub disponível no ambiente ou por `gh issue view NUMERO --repo suap-ava-suite/moodle-quizaccess_presencial --comments`. A leitura fornece o escopo e os critérios de aceite para implementação e revisão. Confirme o repositório quando receber uma URL de outra origem.

Para criar ou atualizar um PR, siga [.agents/skills/criar-pr/SKILL.md](../../.agents/skills/criar-pr/SKILL.md).
