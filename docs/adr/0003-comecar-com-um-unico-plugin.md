# Começar com um único plugin

A primeira versão será entregue somente como `quizaccess_presencial`, que possuirá a regra de acesso, os dados, os convites, o painel autônomo e sua entrada na navegação. Essa opção evita instalação e versionamento coordenados sem necessidade atual; as responsabilidades internas permanecerão separadas para permitir extrair um novo plugin se surgir uma limitação concreta.
