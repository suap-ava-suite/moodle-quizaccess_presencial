# Restringir dados ao período da delegação

O Painel do Aplicador oferece somente a visão operacional necessária para Delegações atuais ou futuras. Quando uma Delegação é revogada, expira ou fica inoperante pela suspensão da conta, o usuário perde imediatamente o acesso ao Questionário e aos dados dos estudantes. Não haverá histórico pessoal desses dados para o ex-Aplicador; os registros permanecem no mecanismo de auditoria destinado a usuários autorizados. Essa escolha reduz exposição de dados pessoais, mesmo que retire do Aplicador a conveniência de consultar aplicações anteriores.
