# Restringir dados ao período da delegação

O Painel do Aplicador oferece somente a visão operacional necessária enquanto o Questionário estiver disponível, ainda não tiver aberto ou tiver Solicitações na Fila operacional. Quando uma Delegação é revogada, fica inoperante pela suspensão da conta ou o Questionário deixa essas condições, o usuário perde imediatamente o acesso ao Questionário e aos dados dos estudantes. Não haverá histórico pessoal desses dados para o ex-Aplicador; os registros permanecem no mecanismo de auditoria destinado a usuários autorizados. Essa escolha reduz exposição de dados pessoais, mesmo que retire do Aplicador a conveniência de consultar aplicações anteriores.
